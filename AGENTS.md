# Project Agent Instructions

## Project Skills

Before starting any task, inspect the project-local skills in `.agents/skills/`.

- Identify every installed skill relevant to the task.
- Read each relevant skill's `SKILL.md` before planning, editing files, or running task-specific commands.
- Follow the skill's workflow and load any referenced files required for the task.
- Use `find-skills` when the available skills do not clearly cover the request.
- Prefer these project-local skills over similarly named global skills.
- Do not skip a relevant skill merely because the task appears straightforward.

The skills are project-scoped. Do not install or modify global skills unless the user explicitly requests it.
